# Pranav Bhawsar — Personal Portfolio

Personal portfolio website for **Pranav Bhawsar**, AI Engineer.

## Run locally

No build step is required.

```bash
git clone https://github.com/Pranavbh1/Pranavbh1.github.io.git
cd Pranavbh1.github.io
```

Open `index.html` in a browser.

## Deploy with GitHub Pages

1. Create a public repository named `Pranavbh1.github.io`.
2. Upload all files from this folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

The site will be available at:

`https://pranavbh1.github.io`
